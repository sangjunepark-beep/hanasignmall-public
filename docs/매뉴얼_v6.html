1이 도구가 뭐냐

하나사인몰 어드민(ad.hanasm.kr)에 등록된 상품의 카테고리 정비 작업을 자동화하는 브라우저 도구입니다.

해결하는 문제

입간판·안내판 등 수백~수천 개 상품에 대해 상품별 카테고리, 업종별 카테고리, 관심분야 공간 체크박스가 제대로 설정돼 있는지 일일이 확인하고 잘못된 걸 수정하는 건 사람이 하면 하루 종일 걸립니다.

이 도구는 북마크 한 번 클릭으로:

  • 전체 페이지 자동 감사 (현재 검색 필터 유지)
  • LLM이 상품명 보고 "어떤 카테고리·공간이 맞는지" 자동 판단
  • 잘못된 거 한꺼번에 바로잡음 (iframe 백그라운드 처리)
  • 문제 생기면 원클릭 롤백으로 되돌림

2첫 설치 (한 번만)

1

Chrome 북마크바 표시

Ctrl + Shift + B 눌러서 주소창 아래 북마크바 켜기

2

북마크 추가

북마크바 빈 영역 우클릭 → "페이지 추가" 클릭. 이름은 🔍 실시간 감사 같이 입력.

URL 칸에 아래 전체를 복사해서 붙여넣기:

javascript:void((async()=>{document.getElementById('hs-audit-root')?.remove();const r=await fetch('https://raw.githubusercontent.com/sangjunepark-beep/hanasignmall-public/main/realtime_audit.js?v='+Math.random(),{cache:'reload'});eval(await r.text());})())
Chrome이 저장 시 앞의 javascript: 부분을 자동으로 지우는 경우가 있습니다. 저장 후 북마크 편집해서 javascript:가 URL 맨 앞에 있는지 확인하세요.
3

Claude API 키 등록 (LLM 판정 사용할 때만)

LLM이 상품명 읽고 자동 판단하게 하려면 Anthropic API 키가 필요합니다.

1) https://console.anthropic.com/settings/keys 에서 API 키 발급 (sk-ant-api03-...)

2) Chrome에서 ad.hanasm.kr 어드민 탭 열고 F12 → Console 탭

3) 아래 두 줄을 Console에 붙여넣기 (중간 키 부분만 본인 키로 교체):

sessionStorage.setItem('hs_anthropic_key', 'sk-ant-api03-여기에본인키');
localStorage.setItem('hs_anthropic_key', sessionStorage.getItem('hs_anthropic_key'));
키는 본인 브라우저에만 저장됩니다. GitHub 리포·스크립트·대화 어디에도 저장되지 않음. 제거는 sessionStorage.removeItem('hs_anthropic_key')
4

어드민 로그인 확인

ad.hanasm.kr 로그인이 유지되고 있는지 확인. 북마클릿은 로그인된 세션 쿠키를 사용하므로 필수.

설치 끝. 이후로는 감사할 때마다 북마크 한 번 클릭하면 됩니다.

3표준 작업 플로우

매번 감사·수정할 때 이 7단계 순서를 지키세요. 특히 ④ Excel 검수와 ⑥ 결과 검증을 스킵하면 데이터 오염 위험이 있습니다.

1

어드민 GoodsList에서 필터 설정

판매상태(판매중), 카테고리(예: 입간판 04), 검색어 등 원하는 조건을 화면에 맞춰두기.

북마클릿은 현재 탭 URL의 쿼리 그대로 감사하므로 필터가 그대로 반영됩니다.

2

[테스트/시연] 범위 축소 (선택)

처음 쓸 때는 1페이지만 돌려 검증 권장. 북마크 실행 전에 F12 → Console에:

window.HS_AUDIT_CONFIG = {pages:[1]};

그 다음 북마크 클릭.

3

북마크 🔍 실시간 감사 클릭

화면 우측 상단에 플로팅 대시보드가 뜨고 자동으로 수집 → 감사 시작.

진행 상황은 실시간 로그로 표시. 전체 페이지 감사까지 1~5분 소요 (상품 수에 따라).

4

🧠 LLM 판정 실행

감사 완료 후 대시보드 하단 버튼 클릭.

FIX 판정된 상품에 대해 상품명을 Claude Haiku 4.5에 전송 → 적합한 3차 코드 + 체크할 공간 코드 자동 추론.

완료까지 30초~2분. 비용은 300건 기준 $0.20~0.35.

5

📊 Excel 다운로드 + 검수

엑셀 파일 열어서 제안 상품별 변경·제안 업종 변경·제안 체크 변경 컬럼 확인.

🧠 표시가 있는 셀은 LLM 판정 결과. 타당해 보이면 다음 단계, 이상하면 여기서 중단.

6

🔧 일괄 자동 수정 실행

주황색 경고 박스 안의 빨간 버튼 클릭.

  1. Confirm 다이얼로그 뜸 → "계속?" 확인
  2. 롤백 백업 JSON 자동 다운로드 → 파일 반드시 보관 (예: 바탕화면)
  3. iframe에 상품별 편집 페이지 로드 → 자동 수정 진행
  4. 완료 시 alert로 성공/실패 건수 보고
7

결과 샘플 검증

수정된 상품 중 1~2개를 어드민에서 직접 열어서 눈으로 확인.

정상 → 범위 확대 가능 (5페이지, 10페이지...). 이상 → 다음 단계(롤백).

8

[이상 시] 🔙 롤백 실행

대시보드 하단 빨간 버튼 클릭.

옵션: [확인] = localStorage 최신 백업 / [취소] = 파일 선택창 → 방금 받은 JSON 선택

체크박스가 백업 시점 상태로 자동 복구. (상품별/업종 카테고리는 현재 CB만 완전 복구 가능)

🚨 절대 규칙: 어드민에서 .click() 기반 수정은 즉시 서버 저장됩니다. 실행하면 실제 상품 데이터가 바뀌므로 ④ Excel 검수 → ⑤ 샘플 확인 두 단계는 절대 건너뛰지 마세요.

영역내용
상단 메트릭 5개전체 / 완료 / OK / FIX / 과태깅 카운트 실시간

페이지별 진행셀1P, 2P, 3P... 각 페이지별 감사 완료 카운트
현재 처리 상품 카드RgrCode, 상품명, O/T, 체크수, 판정 뱃지
실시간 로그타임스탬프 + 태그 + 메시지 순으로 기록
다운로드 영역Excel / CSV / JSON / 복사 버튼

자동 수정 영역🔧 주황색 경고 박스 + 빨간 실행 버튼
백업/롤백 영역🛡️ 초록 백업 목록 + 🔙 빨강 롤백 버튼

감사 기능

현재 URL의 쿼리를 그대로 이어받아 GoodsList.php 각 페이지를 fetch. 판매상태·카테고리·viewCnt 자동 반영.

각 상품의 편집 페이지를 fetch 하여 3차원을 동시 수집:

  • catO (상품별 카테고리) · 1/2/3차
  • catT (업종별 카테고리) · 연결된 업종 9개
  • cbDetail (관심분야 공간 체크박스) · 그룹별 카운트 + 전체 value 배열

🧠 LLM 판정

감사 후 FIX 판정된 상품에 한해 실행. 상품명·현재 O/T·체크수를 Claude Haiku 4.5에 전송하면 다음 JSON 형태로 답변 받음:

{
  "rgr": "240104151418_8287",
  "o3": "04-01-009",                      // 상품별 3차 추가할 코드
  "spaces": ["05-03","06-07","02-01"],   // 재체크할 공간 코드
  "reason": "차량 요일제 주차 관련"
}

📊 Excel 다운로드

xlsx-js-style 기반 3 시트 파일. 시트 1은 전체, 2는 수정필요만, 3은 요약. 14컬럼 Before/After 비교 + 셀별 색상. 상세는 5번 섹션 참조.

🔧 일괄 자동 수정

FIX 판정 상품을 백그라운드 iframe으로 열어 자동 처리:

판정동작
FIX_T누락된 업종만 CateCodeT_1에 선택 → 연결 버튼 click 반복 (최대 9번)
FIX_OLLM이 준 o3 코드로 catO1→2→3 선택 → 추가 버튼 click
FIX_CB체크된 관심분야 체크박스 전부 해제 → LLM 지정 공간만 재체크
FIX_ALL / FIX_MULTI위 3가지 모두 시도

🛡️ 백업 자동 생성

자동 수정 실행 직전에 JSON 백업이 자동 다운로드됩니다.

  • 파일명 예: 롤백백업_04_2026-04-20_14-30-45.json
  • localStorage에도 저장 (키 hs_backup_날짜)
  • 최대 10개까지 자동 보관, 초과 시 오래된 것부터 삭제
  • 내용: 각 상품의 현재 o, t, cc, ct, cd, 그리고 체크된 value 배열 전체 (롤백 완전 복구용)

🔙 원클릭 롤백

두 가지 소스 중 선택:

  1. localStorage 최신 백업 (확인 버튼) — 빠름. 최근 백업 바로 적용
  2. 파일 선택 (취소 버튼) — 원하는 백업 JSON 파일 업로드

체크박스를 백업 시점 value 배열과 비교해 추가된 건 해제, 빠진 건 체크. iframe 기반 순차 처리.

6안전 원칙 (4중 장치)

자동 수정은 어드민 서버에 즉시 반영되어 되돌리기가 어렵습니다. 그래서 4단계 안전장치를 반드시 지킵니다.

1

실행 전 백업 자동 생성

🔧 일괄 자동 수정 버튼 클릭 순간 JSON 파일이 자동 다운로드됩니다. 이 파일을 반드시 보관하세요.

2

Confirm 다이얼로그 승인

실행 건수와 "되돌릴 수 없음" 경고가 표시됩니다. 읽고 확인 누르세요.

3

수정 후 샘플 검증

완료 후 수정된 상품 1~2개를 어드민에서 직접 열어 카테고리/체크박스 상태가 기대와 맞는지 확인.

4

롤백 경로 확보

이상 발견 시 🔙 버튼 → 백업 JSON → 자동 원상복구. 체크박스 단위로 완전 복원 가능.

시연·첫 실행 시 권장: window.HS_AUDIT_CONFIG = {pages:[1]} 로 범위 1페이지 30개로 제한하고 테스트하세요. 소규모에서 문제없음 확인 후 범위 확대.

11자주 묻는 질문

LLM 판정 없이 자동 수정만 돌려도 되나요?

FIX_T(업종 연결)는 LLM 없이도 자동 수정이 정확히 동작합니다. 9업종 전체 연결이 규칙이라 추론 필요 없음.

FIX_CB(과태깅)는 LLM 없으면 전체 해제만 수행되고 재체크는 안 됩니다. 즉 상품이 어떤 공간 체크도 없는 상태가 되어 나중에 수동 재설정 필요.

FIX_O(상품별 3차)는 규칙 기반 추출 가능한 패턴은 자동, 아니면 "보완 필요" 표시만 됨.

권장: LLM 판정을 돌린 뒤 자동 수정. 비용 대비 훨씬 정확합니다.

자동 수정 중에 브라우저 탭을 닫으면?

진행 중이던 수정은 중단됩니다. 이미 click된 것은 서버에 반영되고 남은 건 안 됨.

이런 경우 대시보드 중지 버튼(■) 누르고, 어떤 상품까지 처리됐는지 로그 확인 후 남은 상품만 다시 범위 지정해서 재실행.

여러 카테고리(입간판 + 안내판) 한번에 돌릴 수 있나?

한 번의 북마크 실행은 하나의 카테고리만 처리. 다른 카테고리 하려면 어드민에서 필터 바꾸고 다시 북마크 클릭.

필요하면 카테고리별로 순차 진행 권장 (각각 결과 검증 후 넘어가기).

대시보드가 다른 걸 가려서 어드민이 안 보여요.

대시보드 헤더를 드래그하면 위치 이동 가능. 또는 — 버튼으로 최소화. 또는 ✕ 닫기.

완전히 닫고 나서 다시 북마크 클릭하면 다시 뜹니다.

API 키를 팀원 여러 명이 공유해도 되나?

기술적으론 가능하지만 권장 안 함. 각자 Anthropic 계정에서 별도 키 발급해서 사용하는 게 사용량 추적·한도 관리에 편리.

팀 전체 사용량을 관리하려면 Anthropic Team 플랜 고려.

백업 파일을 얼마나 보관해야 하나?

수정 작업 직후 며칠 ~ 1주일 정도는 보관 권장. 그 후 팀 공유 드라이브에 백업 아카이브로 이동해두면 좋음.

localStorage에도 최대 10개까지 자동 보관되지만 브라우저 데이터 삭제 시 사라지니 파일 보관이 확실.

자동 수정이 실패한 상품은 어떻게 알 수 있나요?

실행 완료 후 alert에 "성공 N / 실패 M" 표시. 실시간 로그에 [FIX ERR] 태그로 어떤 상품이 왜 실패했는지 기록됨.

실패한 상품은 별도로 어드민에서 수동 확인 필요.

iframe이 뭔가요? 왜 백그라운드에서 처리해요?

iframe은 현재 페이지 안에 숨겨둔 별도 브라우저 창. 이 창에 상품 편집 페이지를 로드해서 JavaScript로 자동 조작. 사용자 눈에는 안 보이지만 실제로 어드민에 로그인된 상태로 동작.

덕분에 브라우저 화면은 대시보드 그대로 유지되면서 뒤에서 조용히 수정이 진행됩니다.

수정 결과가 어드민 화면에 바로 반영되나요?

네, 어드민은 .click()이 즉시 AJAX로 서버에 저장되는 구조. 자동 수정 진행 중에도 별도 탭에서 같은 상품을 새로고침하면 변경이 보입니다.

단, 자동 수정 중엔 그 상품을 수동으로 건드리지 마세요 (충돌 가능).

대시보드에서 로그가 너무 빨리 지나가요.

실시간 로그 영역을 스크롤하면 과거 로그 확인 가능. 최대 300줄 유지.

전체 기록이 필요하면 완료 후 JSON 다운로드 받아서 보관. 모든 데이터가 거기 들어있음.
