🚀사용 방법

1
상품 검색 조건 설정
어드민 상품 목록(GoodsList) 화면에서:
• 판매상태: 판매중
• 카테고리: 정리할 것 (예: 입간판)
• 원하는 필터 전부 걸기
2
🔍 실시간 감사 북마크 클릭
화면 우측 상단에 검은 대시보드가 뜨고 자동으로 감사 시작.
1~5분 정도 기다리면 감사 완료. 커피 한 잔 타러 가세요 ☕
3
🧠 LLM 판정 실행 버튼 클릭
AI가 상품명을 읽고 "이 상품은 어떤 카테고리·공간이 맞는지" 자동 판단.
30초~2분 소요. 비용은 상품 100개당 약 100원.
❌ "API 키 없음" 에러 나오면 → 🔑 API 키 설정 북마크 먼저 클릭하고 키 등록하세요.
4
📊 Excel 다운로드 눌러서 확인
엑셀 파일 열어서 AI 제안이 맞는지 눈으로 검토:
• "제안 상품별 변경" 컬럼 = 뭐가 추가될지
• "제안 업종 변경" 컬럼 = 어떤 업종 연결될지
• "제안 체크 변경" 컬럼 = 어떤 공간 체크될지
💡 🧠 표시된 셀이 AI 판단. 이상하면 여기서 멈추고 박상준 차장님께 보고.
5
🔧 일괄 자동 수정 실행 클릭
주황색 경고 박스 안의 빨간 버튼입니다.
📁 백업 JSON 파일이 자동으로 다운로드되니 바탕화면 같은 곳에 꼭 보관!
"계속하시겠습니까?" 물어보면 "확인" 클릭 → 자동 수정 시작.
6
수정 결과 눈으로 확인
끝나면 alert로 "성공 N건" 표시. 어드민에서 상품 1~2개를 직접 열어서 카테고리/체크박스가 잘 반영됐는지 확인.
7
[문제 있을 때] 🔙 롤백 실행 클릭
뭔가 이상하면 당황하지 말고 🔙 롤백 버튼 클릭.
"최근 백업으로 되돌릴까요?" → 확인 누르면 자동으로 원래대로 복구됩니다.
또는 아까 다운로드받은 백업 JSON 파일 선택.
⚠️

꼭 지켜주세요

• 처음 쓸 땐 1페이지만 돌려서 테스트하세요 (박상준 차장님께 물어보기)

• 백업 JSON 파일 반드시 보관 — 수정 후 혹시 모를 롤백용

• 📊 엑셀 검토 꼭 하고 🔧 수정 버튼 누르기 — 이상한 AI 판단 걸러야 함

• 🔧 수정은 되돌리기 어려움 — 확신 없으면 박상준 차장님께 물어보고 진행

• API 키는 절대 외부에 공유 금지 — 유출되면 비용 폭탄

🆘안될 때

  • 북마크 눌러도 안 뜨면: 북마크 편집해서 URL 앞에 javascript: 붙어있는지 확인
  • "이전 버전이 떠요": 🔍 실시간 감사 북마크 URL을 매뉴얼에서 다시 복사해서 교체
  • 🧠 LLM 판정 "키 없음" 에러: 🔑 API 키 설정 북마크 먼저 클릭해서 키 등록
  • 🔑 북마크 눌러도 팝업 안 뜨면: URL 앞 javascript: 가 잘려있음 → 편집해서 다시 추가
  • 팝업에 키 붙여넣기 안 돼요: 키를 직접 타이핑 (또는 키를 일반 메모장에 먼저 복사 후 팝업에 붙여넣기)
  • 감사 중 오류: 어드민 로그인 풀렸을 수 있음 — 다시 로그인 후 재시도
  • 수정 결과가 이상해요: 즉시 🔙 롤백 → 백업 파일 선택 → 복구
  • 해결 안 되면: 화면 캡쳐해서 박상준 차장님께 전달

🔑API 키 관련

키 확인

🔑 API 키 설정 북마크 누르고 팝업에 아무거나 입력 안 하고 취소 눌러도, 이미 등록된 키가 있다면 동작 안 함. 새로 교체하려면 새 키 입력.

키 삭제 (필요 시)

F12 → Console 열고 아래 입력 (이건 짧아서 붙여넣기 제한 안 걸림):

sessionStorage.removeItem('hs_anthropic_key');localStorage.removeItem('hs_anthropic_key');

비용 확인

박상준 차장님만 해당. console.anthropic.com/settings/usage 에서 실시간 확인.
