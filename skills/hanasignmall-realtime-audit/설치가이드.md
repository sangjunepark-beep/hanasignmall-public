# hanasignmall-realtime-audit 스킬 설치 가이드

## 파일 3개

이 폴더에 3개 파일이 있습니다:

- `SKILL.md` — Cowork용 전체 스킬 본문
- `INSTRUCTIONS_for_Project.md` — claude.ai Projects Custom Instructions 복사용
- `설치가이드.md` — 이 파일

## 1) Cowork에 설치

Cowork 스킬 폴더는 읽기 전용이라 Claude가 직접 넣을 수 없습니다. 사용자 PC에서 직접 복사.

### Windows

1. 파일 탐색기 주소창에 `%USERPROFILE%\.claude\skills\` 입력 → Enter
2. 새 폴더 `hanasignmall-realtime-audit` 생성
3. 워크스페이스의 `SKILL.md` 파일을 그 폴더에 복사
4. Cowork 재시작 또는 새 세션 시작
5. 다음 세션에서 `<available_skills>` 목록에 이 스킬이 나타나면 OK

### macOS / Linux

```bash
mkdir -p ~/.claude/skills/hanasignmall-realtime-audit
cp /path/to/SKILL.md ~/.claude/skills/hanasignmall-realtime-audit/
```

## 2) claude.ai Projects에 설치

1. https://claude.ai 접속 → 좌측 "프로젝트" → "+ 새 프로젝트"
2. 이름 지정 (예: `하나사인몰 감사 도우미`)
3. 프로젝트 설정 → **"프로젝트 지침"** 또는 "Custom Instructions" 칸
4. `INSTRUCTIONS_for_Project.md` 본문 전체 복사 → 붙여넣기 → 저장
5. 그 프로젝트 안에서 대화 시작
6. 예: "실시간 감사 돌려줘" 하면 지침대로 안내됨

**주의사항:**
- 8000자 제한 초과 시 일부 섹션 줄여야 함
- claude.ai 채팅에서는 실제 어드민 접근 불가 (안내만 가능)
- 실제 감사·수정은 Chrome 북마클릿에서 실행됨

## 3) 북마클릿 설치 (모든 환경 공통 · 필수)

Chrome 브라우저:

1. `Ctrl+Shift+B` → 북마크바 표시
2. 북마크바 빈 영역 우클릭 → "페이지 추가"
3. 이름: `🔍 실시간 감사`
4. URL:
```
javascript:void((async()=>{document.getElementById('hs-audit-root')?.remove();const r=await fetch('https://raw.githubusercontent.com/sangjunepark-beep/hanasignmall-public/main/realtime_audit.js?v='+Math.random(),{cache:'reload'});eval(await r.text());})())
```
5. 저장
6. 저장 후 URL이 `javascript:`로 시작하는지 확인 (Chrome이 prefix를 지우는 경우 있음)

## 4) Claude API 키 등록 (LLM 판정 사용 시)

1. https://console.anthropic.com/settings/keys 에서 API 키 발급 (`sk-ant-api03-...`)
2. Chrome에서 ad.hanasm.kr 어드민 탭 → F12 → Console
3. 다음 입력 후 Enter:
```javascript
sessionStorage.setItem('hs_anthropic_key', 'sk-ant-api03-여기에키붙여넣기');
localStorage.setItem('hs_anthropic_key', sessionStorage.getItem('hs_anthropic_key'));
```

북마클릿이 자동으로 이 키를 읽어서 사용.

**보안**: 키는 브라우저에만 저장되며 GitHub·스크립트 본체·메모리·Claude 대화 어디에도 저장 X. 키 제거는:
```javascript
sessionStorage.removeItem('hs_anthropic_key');
localStorage.removeItem('hs_anthropic_key');
```

## 5) 사용 순서 (표준 플로우)

1. ad.hanasm.kr 어드민 로그인
2. GoodsList에서 판매상태·카테고리·기간 필터 설정
3. [테스트 시] Console에 범위 축소:
```javascript
window.HS_AUDIT_CONFIG = {pages:[1]};
```
4. 북마크바 🔍 실시간 감사 클릭
5. 감사 완료 후 대시보드에서:
   - 🧠 LLM 판정 실행
   - 📊 Excel 다운로드 → 제안 검수
   - 🔧 일괄 자동 수정 (백업 JSON 자동 다운로드 · 보관 필수)
6. 수정된 상품 1~2개 어드민에서 직접 확인
7. 이상 시 🔙 롤백 실행 → 백업 파일 선택

## 6) 트러블슈팅

| 증상 | 원인 | 해결 |
|------|------|------|
| 북마크 눌러도 반응 없음 | URL에 `javascript:` prefix 삭제됨 | 북마크 편집해서 prefix 재입력 |
| 이전 버전 실행됨 | 캐시 | URL에 `?v=` + `cache:'reload'` 포함 확인 |
| LLM 판정 버튼 안 먹힘 | API 키 미등록 | Console에서 sessionStorage 설정 |
| 가로 스크롤 생김 | 대시보드 폭 부족 | `window.HS_AUDIT_CONFIG = {width: 900}` |
| 글자 너무 작음/큼 | scale 값 | `window.HS_AUDIT_CONFIG = {scale: 2.0}` |
| 자동 수정 중 iframe 타임아웃 | 어드민 느림 | pace 늘리거나 범위 축소 |
