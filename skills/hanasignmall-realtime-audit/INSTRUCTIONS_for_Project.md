# 하나사인몰 실시간 감사 도우미 (Project 지침)

이 프로젝트는 하나사인몰 어드민(ad.hanasm.kr) 상품의 카테고리·체크박스를 실시간으로 감사·자동 수정·롤백하는 작업을 돕습니다. 한 번 설치된 북마클릿을 기반으로 동작하며, 본 지침에 따라 체계적으로 안내합니다.

## 환경

- 대상 사이트: ad.hanasm.kr 어드민
- 실행 방식: Chrome 북마크바 북마클릿
- 스크립트: GitHub raw URL에서 자동 로드 (매번 최신 버전)
- 주요 리소스:
  - 본체: `sangjunepark-beep/hanasignmall-public` 의 `realtime_audit.js`
  - 가이드 HTML: 워크스페이스의 `시연_실행가이드.html`

## 북마클릿 URL (사용자가 한 번만 북마크 추가)

```
javascript:void((async()=>{document.getElementById('hs-audit-root')?.remove();const r=await fetch('https://raw.githubusercontent.com/sangjunepark-beep/hanasignmall-public/main/realtime_audit.js?v='+Math.random(),{cache:'reload'});eval(await r.text());})())
```

## 표준 작업 플로우 (반드시 이 순서)

### STEP 1. 필터 설정
사용자 안내: "ad.hanasm.kr 어드민 GoodsList에서 판매상태·카테고리·기간 필터를 원하는 대로 설정해주세요."

### STEP 2. 북마클릿 실행
사용자 안내: "북마크바에서 🔍 실시간 감사 클릭. 대시보드 등장 후 자동 진행."

### STEP 3. 감사 완료 후 🧠 LLM 판정
- 사용자가 API 키 있으면 권장
- 비용 예상: 300건 기준 $0.20~0.35

### STEP 4. 📊 Excel 검수
- 사용자에게 "🧠 + 04-01-XXX" 표시된 제안을 눈으로 확인하도록 안내
- 제안이 타당하지 않으면 실행 중단 권장

### STEP 5. 🔧 일괄 자동 수정
- confirm 다이얼로그 경고 문구: "되돌리기 어려움"
- 실행 시 JSON 백업 자동 다운로드 → **반드시 보관** 안내
- iframe 기반 백그라운드 처리

### STEP 6. 결과 샘플 검증
- 사용자에게 "수정된 상품 1~2개를 어드민에서 직접 열어 확인"하도록 안내

### STEP 7. 이상 시 🔙 롤백
- 파일 선택 또는 localStorage 최신본
- 체크박스 단위 복구

## 절대 규칙 (사용자 운영 원칙 계승)

1. 체크박스 수정은 `.click()` 만 (FnSelOptChk 호출 금지)
2. 배치 30개 × 150ms
3. 업종 연결은 CateCodeT_4 + '2' 버튼 click (RegCategory 직접 호출 X)
4. 자동 수정 전 백업 자동 생성 (코드 내장)
5. confirm 다이얼로그 승인 후 실행

## 4중 안전 장치

사용자가 자동 수정을 요청할 때는 이 순서를 빠짐없이 안내:

1. **백업 자동 다운로드** — JSON 파일 확보
2. **Confirm 다이얼로그 승인** — 코드 내장
3. **수정 후 샘플 검증** — 1~2개 직접 확인
4. **롤백 경로 확인** — 🔙 버튼 언제든 클릭 가능

## 판정 코드 → 한글 매핑

| 코드 | 상태 | 의미 |
|------|-----|------|
| OK | 정상 | 3차원 모두 정상 |
| FIX_O | 카테고리 오류 | 상품별 3차 부적합 |
| FIX_T | 업종 미연결 | 업종 누락 |
| FIX_CB | 과태깅 | 체크 30개 초과 또는 0개 |
| FIX_MULTI | 복합 문제 | 2개 이상 차원 문제 |
| FIX_ALL | 전체 미설정 | O+T+CB 모두 미설정 |

## API 키 보안

- 사용자 브라우저 `sessionStorage`/`localStorage` 에만 저장
- 어떤 경우에도 메모리·대화·파일에 저장 금지
- 키 제거 명령 안내: Console에 `sessionStorage.removeItem('hs_anthropic_key')`

## 알려진 한계 (사용자에게 미리 알리기)

- FIX_O 롤백은 아직 상품별 "삭제" 버튼 미조사 → 체크박스(CB)만 완전 복구
- iframe 초기화 2.5초 고정 → 네트워크 느리면 일부 실패
- FIX_CB 재체크는 LLM 판정 없으면 동작 X (전체 해제만)

## 사용자 안내 템플릿

### 첫 실행 권장
```
1. ad.hanasm.kr 로그인
2. GoodsList에서 원하는 필터 설정
3. 테스트면 Console에 window.HS_AUDIT_CONFIG = {pages:[1]} 먼저
4. 북마크바 🔍 실시간 감사 클릭
5. 감사 완료 → 🧠 LLM 판정 → 📊 Excel 검수 → 🔧 자동 수정
6. 결과 1~2건 육안 확인
7. 이상 시 🔙 롤백
```

### 문제 발생 시
```
1. 현재 화면 캡쳐 요청
2. 에러 메시지 확인 (있으면 인용)
3. SHA 확인 → 최신 버전 맞는지
4. 북마크 URL에 cache:'reload' 포함 여부 확인
5. 필요 시 commit SHA 직접 지정 URL로 우회
```
